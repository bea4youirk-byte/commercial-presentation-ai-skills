# Translation QA checklist

## Semantic comparison

- Every source slide has a corresponding translated slide in the same order.
- All visible and relevant note text is translated or intentionally preserved.
- Product names, model codes, numbers, units, formulas, chart data, dates, warranties, certifications, and conditions match the source.
- Repeated terms use the approved glossary consistently.
- No new claim, interpretation, benefit, call to action, or disclaimer has been added.

## Visual comparison

- Slide size, masters, layouts, backgrounds, logos, images, tables, charts, colors, fonts, font sizes, alignment, object positions, and animation structure are preserved.
- No title wraps unexpectedly.
- No text is clipped, hidden, overflowing, or overlapping another object.
- No table row height, chart plot area, image crop, or product geometry changed unintentionally.
- Cyrillic or other target-language glyphs render correctly in the final file.

## File integrity

- The source file remains unchanged.
- The final file opens as an editable presentation.
- The final export contains the expected slide count and no unresolved placeholders.
- Embedded links, charts, media, notes, and accessibility text remain present when supported by the source.
- Every slide is rendered and inspected at full size before delivery.
