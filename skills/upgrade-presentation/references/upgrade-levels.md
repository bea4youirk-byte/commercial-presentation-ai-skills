# Upgrade levels

Select one level and state it internally before editing.

1. Polish: fix typos, spacing, clipping, alignment, consistency, and minor copy friction. Preserve structure and design.
2. Copy upgrade: strengthen titles, simplify text, clarify benefits and calls to action. Preserve slide order and visual system.
3. Narrative upgrade: reorder, merge, split, or remove slides to build a coherent argument. Preserve verified facts and brand system.
4. Visual upgrade: modernize composition, typography, imagery, and chart treatment while retaining approved brand identity and content.
5. Full rebuild: reconstruct story and visuals from the evidence base. Use only when explicitly requested or when the source cannot serve the communication job.

Translation-only work is outside these levels: use a faithful translation workflow and do not upgrade.

For every level, protect numbers, specifications, model identities, legal text, claims, source data, logos, and authentic evidence unless the user explicitly authorizes a change and a source supports it.
