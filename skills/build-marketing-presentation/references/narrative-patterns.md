# Narrative patterns

Choose one dominant arc:

- Launch: market change -> old approach breaks -> audience tension -> product mechanism -> proof -> offer -> action.
- Campaign: objective -> audience insight -> strategic idea -> message pillars -> channel execution -> measurement -> decision.
- Product marketing: job to be done -> friction -> category choice -> differentiated mechanism -> use cases -> evidence -> adoption path.
- Partner deck: shared opportunity -> audience fit -> joint value -> operating model -> economics -> proof -> next step.
- Webinar or educational deck: question -> misconception -> explanation -> application -> example -> action.
- Brand story: audience truth -> point of view -> promise -> behavior -> evidence -> invitation.

An agenda is not a narrative. Use section dividers only when they improve comprehension. Prefer takeaway titles that a presenter could say aloud.
